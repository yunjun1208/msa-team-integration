## 복원 시 수정한 코드

`7416d5b`에서 `scripts/ops/Manage-Overnight.ps1`을 수정했다. 보존 EBS에 연결해 복원한 Grafana PVC에 Helm 소유권 메타데이터가 없어서 모니터링 설치가 실패했다. Grafana PVC에만 managed-by=Helm 라벨과 release-name/release-namespace 주석을 merge patch하도록 변경했다. 스토리지 명세와 데이터는 변경하지 않는다. Prometheus와 Alertmanager의 StatefulSet PVC에는 이 소유권을 적용하지 않는다. 관련 회귀 테스트를 추가했고 전체 Python 테스트가 통과했다.

### 사용자 PowerShell에서 수정 게시를 이어갈 때

프로젝트 폴더에서 먼저 `git diff`로 위 두 파일만 변경됐는지 확인한다. 다음 명령은 원격 main을 직접 바꾸지 않고 검토용 브랜치를 만든다.

```powershell
git switch -c fix/checkout-failure-message
git add app/msa/frontend/src/assets/app.js app/msa/frontend/tests/cart.test.cjs
git commit -m "Explain released stock after checkout failure"
git push -u origin fix/checkout-failure-message
```

게시 후 GitHub에서 main 대상 PR을 만들고 CI 통과·승인을 확인한다. 병합 후 이미지 게시 변수와 새 릴리스 PR, Argo 동기화 및 deploy-check까지 성공해야 운영 반영 완료로 집계한다.
