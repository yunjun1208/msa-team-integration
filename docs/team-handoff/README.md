- GitHub는 HTML을 웹페이지로 실행하지 않고 소스로 보여준다. HTML 원본을 다운로드해 연다.
- 이 경로는 정적 인계 자료다. 앱 이미지·Terraform·운영 서비스 동작은 바꾸지 않는다.
- 스크립트 기본 모드는 읽기 전용이다. `--execute`는 QA 주문 또는 실제 장애를 만들므로 점검 시간을 정하고 사용한다.
- 검증 도구에는 대상 계정/context 보호용 식별자가 있다. 자격증명은 포함하지 않는다. 다른 계정에서 바로 실행하는 범용 설치 도구가 아니다.
- 두 모의 테스트 파일을 같은 폴더에서 `python -m unittest discover -s . -p 'test_*.py'`로 실행할 수 있다(12개).
- 실제 경쟁 결과 JSON은 주문 키를 제외한 공개 요약이다. QA #3은 재고가 0이므로 동시 주문 명령을 그대로 반복하지 않는다.
- SES는 샌드박스다. 자체 도메인 인증·일반 고객 발송 승인은 완료하지 않았다.
- 과거 날짜 문서는 당시 이력이다. 최종 결과는 전체 변경 기록을 따른다.

원본 참고 HTML의 정보 구성(요약·흐름도·단계·검증·다운로드)을 참고해 새 자료를 작성했다. 참고 파일의 스크립트·과거 체크 결과는 가져오지 않았다.
