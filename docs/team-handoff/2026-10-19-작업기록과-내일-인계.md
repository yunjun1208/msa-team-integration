## 내일 첫 단계

같은 프로젝트 폴더, 같은 Windows 사용자 PowerShell에서:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/ops/Manage-Overnight.ps1 -Action Resume
```

이전에 종료를 완료했으므로 Prepare나 전체 destroy를 다시 실행하지 않는다.
실제 전체 재구축은 아직 검증하지 않았다. “한 번에 반드시 성공”이라고 보장하지 않는다.
실패하면 오류를 읽고 원인을 고친 뒤 체크포인트 기반으로 Resume을 재실행한다.

스크립트의 복원 순서:
1. 백업 복호화 및 RDS 스냅샷 확인
2. 현재 PC 공인 IPv4 /32를 접근 목록에 추가
3. DNS 별칭 조회를 끈 상태로 AWS 인프라 생성, RDS 스냅샷 복원
4. EKS 접속 및 노드 준비
5. 네임스페이스·스토리지 준비 후 보존 PV/PVC 연결
6. 관리자 bootstrap Secret과 JWT/내부 서비스 키 복원
7. 관리 도구 설치, 새 DB Secret 준비
8. 앱 동기화, Healthy/Synced 확인
9. 새 ALB에 DNS 별칭 연결
10. 배포 버전·이미지·가용성·TLS·HTML·상품 API 검사

완료 뒤 로그인·기존 회원/상품/주문·이미지·Grafana 데이터를 확인한다.
Argo CD 초기 관리자 비밀번호는 새로 생성될 수 있다.
GitHub 변수 두 값을 다시 true로 바꾸고 Verify approved deployment를 실행한다.
